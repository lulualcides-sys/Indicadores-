# Originais fornecidos pelo usuário — lote público 1

Cópias textuais preservadas **sem reescrever intencionalmente a lógica**, copiados dos originais já existentes na Biblioteca do usuário para este repositório público, conforme pedido de 11/11/2026. A autorização para disponibilização pública foi **informada pelo usuário**; não foi comprovada por documentação independente. Avisos de licença e atribuição presentes no código original foram mantidos.

**Este lote NÃO foi baixado diretamente do Telegram durante esta execução**: o navegador público exibe publicações e nomes de anexos, mas não disponibilizou bytes dos documentos para as ferramentas de importação disponíveis. Não indicar estes arquivos como cópias baixadas hoje do Telegram. Alguns originais podem conter referências a canais Telegram no próprio texto.

Os arquivos são **fontes Pine Script/TXT para análise**, não arquivos `.mq5` compilados ou indicadores comprovadamente lucrativos. Precisam de auditoria causal (HTF, pivot, backdating, barstate) antes de extrair padrões para o Nexus.
